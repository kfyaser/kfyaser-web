KF. YASER — PORTFOLIO WEBSITE
=============================

FILES
- index.html: the complete responsive portfolio website
- script.js: mobile navigation, reveal animations, and contact form email draft

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code.
3. In script.js, replace YOUR_EMAIL@example.com with your real email.
4. Open index.html using Live Server. Internet is needed because Tailwind CSS is loaded from its CDN.

IMPORTANT ABOUT THE CONTACT FORM
The included form uses mailto: to prepare an email in the visitor's email application.
It does not store form entries or deliver them automatically in the background.
For a real hosted form that sends inquiries even when a visitor has no email app configured,
connect a form backend/provider (for example Formspree) or build a backend before launch.

BEFORE MAKING IT PUBLIC
- Replace the placeholder email in script.js.
- Replace the sample/concept portfolio cards with real work as it becomes available.
- Be honest that concept projects are demos, not client work.
- Check all text, contact details, and the mobile layout.
- Publish the folder using GitHub Pages, Netlify, or another static host.
- Tailwind's browser CDN is convenient for learning and prototypes; for a production site,
  build Tailwind locally as part of a proper deployment workflow.

No framework build step is required for this starter version.
